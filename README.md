# Nobody---The-Turnaround-korean-fna-translation
Nobody - The Turnaround의 한국어 팬 번역 입니다.
노바디 한국어 패치 1.0

설치 방법
1. 게임을 종료합니다.
2. Nobody.exe가 있는 게임 폴더에 이 ZIP의 내용을 풀고 덮어씁니다.
   압축을 푼 뒤 Nobody.exe 옆에 Nobody_Data 폴더가 있어야 합니다.
3. 게임 설정의 언어를 English로 선택합니다.

일반 문구와 대사 12,327개를 한국어 번역했습니다.
제작사 공지는 번역하지 않았습니다.
게임 전용 폰트 4종은 나눔고딕으로 교체했습니다.


제거 방법
Steam 라이브러리에서 게임 속성 > 설치된 파일 > 게임 파일 무결성 확인을 실행합니다.
게임 업데이트나 무결성 확인으로 패치가 해제되면 다시 적용해야 합니다.
다른 버전의 게임에는 그대로 적용되지 않을 수 있습니다.
